# 多帕首頁改版紀錄

## 範圍與內容

依照使用者指定的白色、藍色、可愛風格，重做原有靜態網站。保留原有的 15 個不同外部連結、34 個不同圖片素材、5 支影音、7 張官方主視覺、21 件二創及其完整作者與委託人資訊、5 筆活動日期。原頁所有文字與資源屬性另存於 `original-content.json`，可閱讀的摘錄在 `content-inventory.md`。

頁面順序：首頁招呼 → 基本介紹 → 角色故事 → 直播日常與喜好 → 音樂作品 → 官方相簿 → 活動紀錄 → 製作老師 → 粉絲二創 → 社群、聯絡、周邊與贊助入口。

## 文案

依 humanizer-zh 改寫敘述，以第一人稱介紹多帕。保留「狗即狗」、「養樂多」的由來、法條哄睡、水管、裙子不能吃、徽章失蹤等原有笑話與感受。移除公關式的客套與抽象感謝，改用具體事件和自然長短句。作品名稱、日期、帳號、聯絡地址及作者資訊不改寫。所有事實均來自原頁，本次沒有重新查證外部來源。

例如：

- 原文：多帕是一隻薩摩耶 VTuber，生日是 11/20，身高 155 公分（不含耳朵），體重號稱 12 個罐罐。
- 改寫：我是多帕，一隻薩摩耶 VTuber。11 月 20 日生日，身高 155 公分，耳朵不算。體重？12 個罐罐！

編輯自評（主觀，不代表外部評測）：直接性 9、節奏 9、信任度 9、真實性 10、精煉度 9，合計 46/50。

## 設計

「藍白色的狗狗手帳」：純白內容底、淡藍分區、藍色文字與主要按鈕。首頁用原角色頭像，搭配相片紙框及狗掌貼紙；相簿用輕微傾斜的白色相紙。不重新生成角色或改動原作。

- 主色 `#287bb9`、文字 `#294b63`、淡藍底 `#eff8fd`、白底 `#ffffff`。
- 字體：Nunito、Kiwi Maru，搭配系統繁體中文字體。Google Fonts 無法載入時仍能正常閱讀與操作。
- 首頁雙欄，手機改為文字、插畫上下排列；人物資訊、影音、相簿、時間軸各用適合內容的版型。
- 所有資料仍是靜態 HTML。JavaScript 只增强瀏覽體驗，沒有框架或建置依賴。
- 作品圖片可直接連結原檔；支援 dialog 的瀏覽器可在頁面內放大，保留作者資訊，支援 Escape、關閉按鈕與背景關閉。
- 二創預設顯示 6 件，按鈕展開全部 21 件。未執行 JavaScript 時直接顯示全部，列印也保留全部。

內建圖片生成工具在此環境不可用，因此沒有生成或取得使用者批准的概念圖；採用現有素材直接設計。驗證依上述設計方向與實際瀏覽器畫面進行，不宣稱完成概念圖像素對照。

## 驗證

- 排版：以上寬度皆無頁面水平溢出。修正 320 像素首頁英文名過寬，以及人物標題末字落單。
- 字體：桌面大標題和手機中文字大小分別調整；小手機的二創改為單欄，保留作者與留言可讀性。
- 色彩：白、淡藍、主藍一致；原插畫不加色罩。
- 素材：官方相簿與粉絲作品均保留原檔。二創採完整圖像呈現；縮圖與放大連結已核對。

- 文案：首頁內容與本次改写一致；原資訊保存在摘錄，原有外部 URL、二創署名、圖片與活動日期經程式比對通過。
